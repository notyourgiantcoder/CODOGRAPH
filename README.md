# CODOGRAPH

- [`codograph/`](codograph) — the app: reads a public GitHub repo and draws it as a dependency map.
- [`landing-page/`](landing-page) — the marketing landing page.

Each folder is its own Next.js project. Install and run them separately:

```bash
cd codograph && pnpm install && pnpm dev
cd landing-page && npm install && npm run dev
```
